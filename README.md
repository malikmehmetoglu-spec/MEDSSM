# منصة إدارة السلامة والحماية المدنية — وزارة الطوارئ وإدارة الكوارث

منصة لمتابعة خطط الحماية الذاتية للمنشآت (نموذج 2027): بنود الخطة الـ17، حساب نسب التشكيلات واستيعاب الملاجئ، صيانة أجهزة الإطفاء، المخططات الملحقة، سجل الحوادث والتدخل، والتنبيهات الآلية.

صفحة HTML واحدة مستقلة (الخطوط والشعار مضمّنة). البيانات تُحفظ في متصفح المستخدم (localStorage).
